# 고전한입 관리자 · Classic Bites Admin

고전한입의 책·작품·목차·학습 본문을 관리하는 독립 관리자 프로젝트입니다. 원격 저장소는 `xixirepository/classic-bites-admin`이며, iOS 앱과 콘텐츠 API는 각각 별도 저장소에서 관리합니다.

서재 최상위에는 사서오경을 한 권으로 표시합니다. 대학·중용 등은 사서오경 내부 작품이며, 관리자가 다른 책을 등록·공개하면 iOS가 콘텐츠 API를 다시 조회하여 표시하도록 개발합니다.

사용자가 선택한 기술은 Python·FastAPI로 제공하는 관리자 화면과 HTML·CSS·JavaScript입니다. 프런트엔드 프레임워크는 추가하지 않습니다. 기존 FastAPI 백엔드가 MySQL 콘텐츠와 MinIO 표지를 관리하며 이 프로젝트는 관리 API를 호출합니다. 관리자 서버에 데이터베이스나 MinIO 자격증명을 복제하지 않습니다.

현재 단계는 기본 문서와 작업 브랜치 준비입니다. 실행 명령과 검증 결과는 구현 후 실제 확인한 내용으로 보완합니다. 운영 주소·HTTPS 배포는 아직 정해지지 않았습니다.

## 작업 정책

[AGENTS.md](AGENTS.md)를 먼저 읽고 로컬 `dev`에서 작업 브랜치를 만듭니다. 구현과 자동 검증 후 사용자 테스트 확인을 받으며, 승인 전 통합용 rebase·squash·병합을 하지 않습니다. push는 사용자가 직접 수행합니다.
